🚀 Career Intelligence & Opportunity Analytics Platform

An AI-powered career analytics platform developed using Python and Streamlit. The system helps users analyze resumes, identify skill gaps, match jobs, receive career recommendations, and explore market demand trends through interactive dashboards and visualizations.

Problem

Students and job seekers often struggle to understand whether their skills align with industry requirements. Identifying suitable career paths and understanding missing skills can be difficult without proper analysis.

The goal of this project was to build an intelligent platform that helps users evaluate their resumes, compare skills with target roles, and make better career decisions using data-driven insights.

Features

  • Resume PDF Upload & Analysis
  • Skill Extraction from Resumes
  • Job Match Scoring
  • Skill Gap Detection
  • Career Recommendations
  • Market Insights Dashboard
  • Interactive Visualizations

Tools Used

  • Python
  • Streamlit
  • Pandas
  • Plotly
  • PyPDF2
  • HTML/CSS

Key Outcomes

The platform successfully analyzes resumes, identifies technical skills, matches candidates to relevant roles, and provides recommendations based on skill alignment.

Interactive dashboards help users understand current market demand for popular analytics and technology skills, enabling more informed career planning decisions.
